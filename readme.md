# LeetCode 75 — JavaScript

Repositório dedicado ao estudo e resolução dos **75 problemas do LeetCode 75**, utilizando JavaScript.

O objetivo é desenvolver **raciocínio algorítmico, reconhecimento de padrões, domínio de estruturas de dados e análise de complexidade**, e não apenas acumular soluções.
